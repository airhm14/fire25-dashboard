## 1. 대시보드가 하는 일

대시보드는 아래 3가지를 한 화면에서 제공합니다.

```
내 포트폴리오 입력 (사이드바)
         │
         ├─▶  Tab 1  나의 자산 가치, 비중, FIRE 달성 확률
         │
         ├─▶  Tab 2  실시간 시세, VIX, Fear&Greed, 차트, 백테스트
         │
         └─▶  Tab 3  거시경제 이벤트 + 🚀 AI 전략 실행
                             │
                    ┌────────▼──────────┐
                    │  Gemini           │  뉴스·이벤트 분석
                    │  Claude           │  신호 충돌 해석
                    │  GPT-o1           │  교차 검증
                    │  Manual Guard     │  11개 투자 규칙 체크
                    │  실행 계획        │  BUY / HOLD / REDUCE 주문
                    └───────────────────┘
```

**핵심 특징**
- Yahoo Finance 실시간 시세 (15~20분 지연)
- Gemini → Claude → o1 순의 3중 AI 검증
- NORMAL / DEFCON / PUDDLE / SMART_SHOULDER 레짐 기반 전략
- 동일 시장 상황이면 캐시로 즉시 전략 반환 (불필요한 API 비용 절감)
- Google Sheets 포트폴리오 이력 자동 저장

## 2. 처음 시작하기 — 사이드바 입력

화면 왼쪽 **사이드바**에서 현재 보유 수량과 현금을 입력합니다.
이 값이 전체 분석의 기준이 됩니다.

### 보유 주식 수량

| 입력 항목 | 설명 |
|-----------|------|
| **QQQM** | 나스닥 100 ETF 보유 주수 |
| **SCHD** | 배당 성장 ETF 보유 주수 |
| **IAU** | 금 ETF 보유 주수 |
| **SGOV** | 단기 국채 ETF 보유 주수 |

### 현금

| 입력 항목 | 설명 |
|-----------|------|
| **Cash Deposit** | 증권 계좌 예수금 (USD) |
| **New Cash** | 이번 달 신규 투입 예정 금액 (월급·보너스 등) |

> 주식 수량을 0으로 두면 해당 자산은 미보유로 계산됩니다.

### 버튼 & 모드

| | 설명 |
|--|------|
| 🔄 **Refresh** | 캐시 초기화 후 최신 시세 재조회 |
| 💾 **Save** | 현재 포트폴리오를 Google Sheets에 저장 |
| **Personal Mode** | Google Sheets 연동 — 포트폴리오 이력 저장 |
| **Public Mode** | 데모 모드 — 저장 없이 분석만 |

## 3. Tab 1 · 내 자산 현황

포트폴리오의 현재 상태를 요약하는 탭입니다.

### 상단 지표 카드

```
┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐
│  총 자산  │  │  QQQM%  │  │  SCHD%  │  │   IAU%  │  │  현금%  │
│ $XX,XXX  │  │   72%   │  │   16%   │  │    2%   │  │   10%   │
└──────────┘  └──────────┘  └──────────┘  └──────────┘  └──────────┘
         오늘 하루 예상 손익: +$XXX (+0.X%)
```

### 자산 상세 테이블

| 컬럼 | 설명 |
|------|------|
| Value | 현재 시세 × 보유 주수 |
| 현재 비중 | 총 자산 대비 실제 비중 |
| 목표 비중 | FIRE 25 전략 목표 비중 |
| Diff | 현재 - 목표 (양수 = 과다 보유, 음수 = 부족) |

### 포트폴리오 이력

Google Sheets에 저장된 과거 기록으로 자산 변동 추이를 그래프로 표시합니다.
(Personal Mode 전용)

### FIRE 시뮬레이터

은퇴 목표 달성 가능성을 **몬테카를로 시뮬레이션**으로 계산합니다.

| 입력 | 설명 |
|------|------|
| 투자 자산 | QQQM / SPY / VTI / BTC-USD 선택 |
| 연평균 수익률 | 슬라이더로 직접 설정 |
| 투자 기간 | 5~40년 |
| 목표 금액 | FIRE 달성 기준 금액 |

**결과 항목**
- 중앙값 (50th percentile) 최종 자산
- 하위 5th percentile — 보수적 시나리오
- 상위 95th percentile — 낙관적 시나리오
- **목표 달성 확률 (%)**

## 4. Tab 2 · 시장 현황

실시간 시세와 기술적 분석을 확인하는 탭입니다.

### ETF 시세 카드

QQQM · SCHD · IAU · SGOV의 현재가, 등락률(%), 거래량을 표시합니다.

### VIX & 공포·탐욕 지수

| 지표 | 의미 | 수준 가이드 |
|------|------|------------|
| **VIX** | 시장 변동성 (공포 지수) | ~14: 과열, ~20: 안정, 30+: 위험 |
| **Fear & Greed** | 투자 심리 (0~100) | ~25: 극단적 공포, ~75: 극단적 탐욕 |

### 시장 레짐 판단

기술적 지표 기반으로 현재 시장 상태를 분류합니다.

| 레짐 | 조건 요약 |
|------|-----------|
| 🟢 상승장 (BULL) | 가격 > SMA50 > SMA200, VIX 낮음 |
| 🟡 조정장 (CORRECTION) | 가격 < SMA50, VIX 20~30 |
| 🔴 하락장 (BEAR) | 가격 < SMA200, VIX > 25 |
| 🔵 회복장 (RECOVERY) | RSI 상승 전환, VIX 완화, SMA200 재돌파 |

### 핵심 거시 지표 카드

VIX · Fear&Greed · 10Y 국채 금리 · 유가 4개를 한눈에 확인합니다.

### QQQM 기술적 지표

| 지표 | 해석 |
|------|------|
| **RSI** | 30 이하: 과매도 / 30~70: 중립 / 70 이상: 과매수 |
| **SMA 20/50/100/200** | 현재가가 해당 이평선 위/아래 표시 |

### QQQM 차트

캔들스틱 + SMA 20/50/100/200 오버레이 차트와 RSI 서브플롯을 제공합니다.

### 백테스트

PUDDLE(웅덩이) 전략의 과거 성과를 시뮬레이션합니다.
> CAGR · 총수익률 · MDD · 샤프 지수 · 거래 횟수 확인 가능

### 전략 연구실

| 모드 | 설명 |
|------|------|
| 단일 실행 | 투입 비율 직접 설정 후 결과 확인 |
| 현금 비중 연구 | 5~30% 구간별 성과 비교 |
| 쿨다운 연구 | 10~60일 구간별 성과 비교 |
| 다중 자산 검증 | QQQM vs SPY vs VTI vs BTC-USD 비교 |

## 6. AI 전략 오케스트레이터 단계별 해설

🚀 **AI 전략 실행** 버튼을 누르면 아래 7단계가 순서대로 실행됩니다.

```
[입력: 포트폴리오 + 시장 지표 + 뉴스]
         │
         ▼
   ① Regime Gate       → 현재 시장 전략 레짐 판단
         │
         ▼
   ② Gemini 뉴스 분석  → 뉴스 이벤트 구조화 · 스냅샷 생성
         │
         ▼
   ③ News Agent        → 핵심 신호 다이제스트 생성
         │
         ▼
   ④ Signal Analyzer   → 신호 충돌 감지 + Claude 해석
      (Claude)
         │
         ▼
   ⑤ Cross Validator   → 독립 수치 검증 + 규칙 위반 체크
      (GPT-o1)
         │
         ▼
   ⑥ Manual Guard      → 11개 투자 원칙 강제 적용
         │
         ▼
   ⑦ 실행 계획 생성    → 종목별 BUY / HOLD / REDUCE 주문
```

---

### ① Regime Gate — 전략 레짐 판단

현재 시장이 어떤 국면인지 판단합니다. (→ [Section 7](#7-시장-레짐regime-완전-해설) 상세 설명)

**결과 표시 예시**
```
[ NORMAL ] 신뢰도 78% | API 1콜 | 신규 전략 생성
이유: VIX 안정 / QQQM SMA200 상회 / 심리 중립
```

레짐 결과 아래에 **AI 해석 기준 지표 배너**가 표시됩니다.

```
📊 AI 해석 기준 지표 | VIX 27.34 · Fear&Greed 35 (공포) · 10Y 금리 4.28% · 유가 $72.10 · QQQM RSI 48.2 · SMA200 갭 -2.15%
```

> 이 수치가 AI가 실제로 참조한 값입니다. UI 상단 시세 카드와 일치해야 정상입니다.

**전략 일관성 메타데이터**

```
🔑 Hash: a3f1b2c4d5e6  💾 Cache: 🔴 MISS  📊 Regime: ⚡ 변경됨  ♻️ 전략: 🆕 신규 생성
```

| 항목 | 의미 |
|------|------|
| Hash | 동일 입력이면 동일 해시 → 캐시 재사용 |
| Cache HIT | 동일 상황 캐시 적중 → AI 호출 없이 즉시 반환 |
| Cache MISS | 새로운 상황 → AI 신규 호출 |
| Regime 변경됨 | 레짐이 이전과 달라져 새 전략 생성 |
| Regime 유지 | 이전 전략 재사용 (Regime Lock) |

### ② PUDDLE 동적 비중 (PUDDLE 레짐일 때만 표시)

PUDDLE(웅덩이) 국면 진입 시 VIX · 낙폭 · 시장 폭을 반영해 투입 비중을 동적으로 산출합니다.

| 항목 | 설명 |
|------|------|
| 기준 비중 | 단계별 기본 투입 비율 |
| 동적 계수 | VIX · 200MA 낙폭 · 시장 폭 기반 조정 계수 |
| 조정 비중 | 기준 비중 × 동적 계수 |
| 최종 비중 | 상·하한 캡 적용 후 최종값 |

---

### ③ 조기 경보 시스템

매수 차단 여부와 주의 알림을 자동으로 판정합니다.

| 코드 | 의미 |
|------|------|
| `QQQM_MA50_BREAK` | QQQM이 50일 이평선 아래로 이탈 |
| `VIX_SPIKE` | VIX 급등 감지 |
| `YIELD_INVERSION` | 장단기 금리 역전 |
| `DRAWDOWN_ALERT` | 200일선 대비 낙폭 과다 |

- 🔴 **매수 차단 (Buy Block)** — 해당 코드 이유로 이번 매수 차단
- 🟡 **활성 알림 (Alert)** — 주의 필요, 차단은 아님

### ④ Gemini 뉴스 분석

7개 카테고리로 수집한 뉴스 기사를 분류·요약합니다.

```
헤드라인 요약: "연준 금리 동결 시사, 나스닥 반등 기대감..."
원본 뉴스: 48건 → 중복 제거 후: 12건
Macro Bias: slightly_risk_off
QQQM 자산 편향: +1 (매수 선호)
```

### ⑤ News Agent 다이제스트

Gemini가 구조화한 이벤트를 바탕으로 핵심 신호를 3개 추출합니다.

```
한 줄 요약: "금리 불확실성 지속, 기술주 단기 반등 가능성"

핵심 신호:
  ① 연준 발언 → 금리 인하 기대 상향  [risk_on ↑]
  ② 유가 하락 → 인플레이션 압력 완화  [risk_on ↑]
  ③ 지정학 긴장 지속 → 안전자산 선호  [risk_off ↓]
```

---

### ⑥ 신호 충돌 해석 (Signal Analyzer · Claude)

기술적·거시·뉴스 신호 간의 충돌을 5가지 규칙으로 자동 감지한 뒤 Claude가 해석합니다.

**충돌 감지 규칙**

| 규칙 | 충돌 조건 |
|------|-----------|
| 1 | QQQM MA50 상회 + 뉴스 risk_off |
| 2 | QQQM MA200 하회 + 뉴스 risk_on |
| 3 | 거시 낙관 + 경보 2개 이상 |
| 4 | NORMAL 레짐 + VIX ≥ 25 |
| 5 | 뉴스 QQQM 매수 편향 + MA50 이탈 차단 |

**충돌 없음 → ✅ 일관된 지표 방향** (Claude 호출 없이 즉시 반환)

**충돌 감지 시** Claude가 분석하는 항목:

| 항목 | 설명 |
|------|------|
| 상황 요약 | 현재 충돌 상황 2~3문장 해석 |
| 유사 과거 국면 | 비슷한 과거 사례와 그 결과 |
| 전략 일관성 | consistent(일관됨) / caution(주의) / inconsistent(불일치) |
| 핵심 리스크 | 현재 국면의 가장 중요한 리스크 |
| 검토 포인트 | 참고 권고사항 (매수/매도 직접 지시 없음) |

---

### ⑦ o1 교차 검증 (Cross Validator)

Claude 해석을 GPT-o1이 **수치·확률 관점**에서 독립 검증합니다.

| 검증 결과 | 의미 |
|-----------|------|
| ✅ **agree** (동의) | Claude 해석과 일치 |
| 🟡 **partial** (부분 동의) | 일부 이견 있음 |
| ❌ **disagree** (이견) | Claude와 다른 판단 |

**정량 체크 항목**

| 항목 | 내용 |
|------|------|
| VIX 수준 | 현재 VIX 수준과 시장 의미 |
| 금리차 | 10Y-2Y 스프레드 해석 |
| 낙폭 | 200일선 대비 낙폭 해석 |
| 기술적 정렬 | aligned / mixed / conflicting |

**규칙 위반 자동 감지:** QQQM 80% 초과 권장 등 투자 원칙 위반 시 자동 경고

---

### ⑧ 최종 전략 & 실행 계획

**최종 전략 표시 예시**
```
시장 관점: "기술적 강세 유지 중이나 뉴스발 리스크오프 주의 필요"
전략 근거: "MA50 상회 + 심리 중립 → 보수적 홀드 유지"
현금 액션: KEEP
신뢰도: 75/100
```

**실행 계획 표시 예시**
```
┌──────────────────────────────────────────────┐
│  종목     액션    주수   예상 금액            │
│  QQQM     BUY     10주   ~$2,340             │
│  SCHD     HOLD    —      —                   │
│  IAU      HOLD    —      —                   │
│  SGOV     HOLD    —      —                   │
├──────────────────────────────────────────────┤
│  요약: QQQM 10주 매수                        │
│  잔여 현금: $5,660                           │
└──────────────────────────────────────────────┘
```

**전략 안정화 장치 (Strategy Stabilizer)**

| 규칙 | 값 | 설명 |
|------|----|------|
| 일일 비중 변동 캡 | ±5% | 하루 최대 비중 변화 제한 |
| 최소 거래 필터 | 1% | 포트폴리오 대비 1% 미만 → HOLD 전환 |
| 일일 현금 사용 캡 | 25% | 가용 현금의 25% 초과 사용 불가 |

> ⚠️ 모든 AI 결과는 **참고용**입니다. 실제 매매는 본인이 직접 브로커에서 실행하세요.

## 7. 시장 레짐(Regime) 완전 해설

레짐은 AI가 어떤 전략을 쓸지를 결정하는 **핵심 상태**입니다.

### 🟢 NORMAL — 정상 국면

**조건:** 시장이 정상적으로 움직이는 상태
**전략:** 목표 비중 유지, 신규 현금은 비중에 맞게 배분

---

### 🟡 DEFCON — 과열 방어 국면

**조건:** VIX ≤ 14 **그리고** QQQM RSI ≥ 70 (두 조건 동시 충족)
**의미:** 시장이 단기 과열 → 현금 비중을 늘려 다음 조정을 대비
**전략:** 신규 현금을 SGOV(단기 국채)에 먼저 적립, 성장 자산 매수 차단

---

### 🔵→🔴 PUDDLE — 웅덩이 전략 (분할 매수)

200일 이동평균선 하향 이탈 시 단계별로 매수합니다.
**같은 단계에서는 30거래일 쿨다운 후 재매수 가능합니다.**

| 단계 | 조건 | 투입 비율 | 색상 |
|------|------|-----------|------|
| **PUDDLE_1** | 200일선 1차 이탈, 변동성 높음 | 0% (관망) | 🔵 파랑 |
| **PUDDLE_2** | 낙폭 확대 | 현금의 10% | 🟣 보라 |
| **PUDDLE_3** | 낙폭 심화 | 현금의 25% | 💜 진보라 |
| **PUDDLE_4** | 최대 낙폭 / 회복 초입 | 현금의 50% | 🔴 빨강 |

> VIX와 낙폭에 따라 **동적 계수**가 적용되어 실제 투입 비율이 조정됩니다.

---

### 🟠 SMART_SHOULDER — 리밸런싱 국면

**조건:** QQQM 비중 > 77% **그리고** SMA20 하회 **그리고** 52주 고점 근접
**의미:** 성장주 집중도가 너무 높아 리밸런싱 필요
**전략:** QQQM 일부 매도 → 72/16/2/10 목표 비중으로 복귀

---

### 레짐 전환 조건 요약

```
VIX ≤ 14 + RSI ≥ 70  ──────────────────────→  DEFCON
QQQM 200일선 이탈     ──────────────────────→  PUDDLE_1 → 2 → 3 → 4
QQQM 비중 > 77% + 고점 ─────────────────────→  SMART_SHOULDER
그 외 정상            ──────────────────────→  NORMAL
```

|------|------|

### 매뉴얼 가드 — 11대 투자 규칙

AI가 도출한 전략이 원칙을 위반하면 **전 종목 HOLD로 보정**합니다.

| 규칙 | 내용 |
|------|------|
| 허용 종목 | QQQM · SCHD · IAU · SGOV만 거래 가능 |
| 허용 액션 | BUY · HOLD · REDUCE만 가능 |
| 현금 액션 | KEEP · DEPLOY · INCREASE만 가능 |
| 정수 주문 | 소수점 주문 불가, 정수 주수만 허용 |
| 레짐 규칙 | DEFCON: 성장 자산 매수 차단 / SMART_SHOULDER: QQQM 매수 차단 |
| QQQM 코어 | REDUCE는 Smart Shoulder 또는 구조적 리스크 시만 |
| QQQM 비중 캡 | 80% 초과 → 반드시 감량 / 77~80% → 매수 불가 |
| 편차 한도 | QQQM ±5% · SCHD ±3% · IAU ±2% |
| SGOV 상한 | 최대 20% (DEFCON 제외) |
| 일일 비중 변동 | 최대 ±5% / 일 |
| 일일 현금 사용 | 최대 25% / 일 |

## 11. 자주 묻는 질문 (FAQ)

**Q. AI 전략 실행이 느린 이유는?**
A. Gemini → Claude → o1 순으로 3개 AI를 순차 호출하기 때문입니다.
동일한 시장 상황(동일 해시)이면 캐시에서 즉시 반환합니다. 결과 화면에 `📦 캐시 사용` 태그가 표시됩니다.

---

**Q. "전략 재사용 (Regime Lock)"이 뭔가요?**
A. 시장 레짐이 이전과 변하지 않았을 때 기존 전략을 그대로 유지하는 기능입니다.
아래 조건 중 하나라도 해당하면 새 전략을 생성합니다:
- Smart Shoulder 새로 발동
- PUDDLE 더 깊은 단계 진입
- Manual Guard 위반 감지

---

**Q. VIX 값이 다른 사이트와 왜 다른가요?**
A. Yahoo Finance의 15~20분 지연 데이터를 사용하기 때문입니다.
AI 해석 기준 지표 배너에 표시되는 값이 AI가 실제 참조한 수치이므로, 이 값이 UI 상단 시세 카드와 일치하면 정상입니다.

---

**Q. PUDDLE 쿨다운이란?**
A. 동일 PUDDLE 단계에서 매수 후 **30거래일** 동안 같은 단계 재매수를 차단합니다.
더 깊은 단계(예: PUDDLE_2 → PUDDLE_3)로 진입하면 쿨다운과 무관하게 새 매수가 가능합니다.

---

**Q. AI가 매수를 권장하면 자동으로 주문되나요?**
A. **아닙니다.** 대시보드는 자동 매매 기능이 없습니다.
실행 계획에 표시된 주문을 확인 후, 본인이 직접 브로커 앱에서 실행해야 합니다.

---

**Q. "신호 충돌 없음"이 좋은 건가요?**
A. 예. 기술적 지표와 뉴스·거시 신호가 같은 방향을 가리키는 상태입니다.
충돌이 없으면 Claude 호출을 건너뛰어 API 비용도 절감됩니다.

---

**Q. Google Sheets 없이 사용할 수 있나요?**
A. 가능합니다. Public Mode에서는 Google Sheets 없이도 모든 분석 기능을 사용할 수 있습니다.
포트폴리오 이력 저장·조회만 불가능합니다.

---

**Q. API 비용은 얼마나 드나요?**
A. 시나리오별 API 호출 수:

| 시나리오 | 호출 수 |
|----------|---------|
| 캐시 적중 | 0콜 |
| 신호 충돌 없음 | 1콜 (Gemini만) |
| 신호 충돌 발생 | 3콜 (Gemini + Claude + o1) |

모델 비용은 각 API 제공사 정책을 따릅니다.
